FretFlow — local guitar practice for Mac

Build with zsh scripts/build.sh, then open dist/FretFlow.app.
macOS 14+ and Xcode 16+ (or a macOS 15+ SDK) are required.

Add tabs accepts PDF and Guitar Pro .gp/.gp3/.gp4/.gp5/.gpx files.
Imports go to ~/Library/Application Support/FretFlow/Imports; originals are
unchanged. No personal tab files are distributed with the source.

PDF practice
- Use the reader toolbar for pages, zoom and Fit. Reading position and zoom
  are saved separately for each library song.
- Right-click an entry to edit title, artist and collection, or add a song
  using physical PDF page numbers. Sections share the original imported book
  and can each have their own video and practice state.
- PDFs do not provide automatic measure following, matching, or score clicks.
  See docs/PDF-SYNC.md for the recognition and validation still required.

Video and practice
- Paste a YouTube URL and Link video. The choice is saved for this song.
- Optional recording suggestions use title/artist and require a local YouTube
  Data API key. Searches run only when requested; confirm a result to link it.
  Manual links and Find on YouTube require no key. Never put credentials in git.
- Playback position and accepted speed are saved per song/video; reopening does
  not autoplay. Replacing a recording starts separate practice state.
- Set A and B, name the loop and Save. Choose a saved loop, then Play.
- Optional four-beat count-in uses the chosen BPM and system alert sounds before
  Play. PDF tempo is not inferred. It is not a score-based click track.
- Guitar Pro scores additionally support part selection, measure seeking,
  Follow, score clicks and experimental recording alignment. Recording matching
  processes only the app's playback audio locally and applies confident matches.
  Saved corrections remain specific to the exact score and linked video.
- YouTube controls ads, availability, embedding and sign-in restrictions.
  FretFlow does not download YouTube audio or video.

Tuner
- Choose 6 strings, 7 strings or Chromatic, then a preset or custom tuning.
  Notes in custom tunings are ordered low to high. Start microphone and allow
  macOS permission. Capture uses the built-in MacBook microphone.
- Keep an unplugged electric close to the microphone, mute other strings, and
  let one note ring. Select a target string to lock it; the target does not
  force the measured pitch into tune. Leaving Tuner stops microphone capture.
- Audio is processed locally and is not saved or uploaded.

Verification
Run bash scripts/check.sh. Synthetic tuner tests are distinct from real guitar
and microphone testing. Node checks run on Linux; Swift checks require swiftc,
and native UI/audio/WebKit checks require macOS. No current Linux run validates
macOS compilation, a real microphone, live YouTube, or real-song PDF sync.
See docs/VERIFICATION.md for configuration and specific manual Mac checks.
